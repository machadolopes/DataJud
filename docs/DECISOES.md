# Decisões de engenharia

Registro de desvios, interpretações e pinos de versão em relação a `docs/SPEC.md`.
Alterações de stack exigem entrada aqui **e** confirmação antes de seguir.

## F0 — Fundação

| Tema                                       | Decisão                                                                  | Justificativa                                                                                                                                                                                                                |
| ------------------------------------------ | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Next.js                                    | `16.3.6` (App Router)                                                    | Versão estável atual na data da F0, com correção de segurança de 22/09/2026 (`GHSA-vcvr-r3jv-pc5j`).                                                                                                                         |
| React                                      | `19.2.8`                                                                 | Par da instalação oficial do `create-next-app@16.3.6`.                                                                                                                                                                       |
| Tailwind CSS                               | v4 (`@import "tailwindcss"`)                                             | Padrão do template oficial do Next.js 16. shadcn/ui entra na F1.                                                                                                                                                             |
| Prisma                                     | v6, generator `prisma-client-js`, schema em `apps/web/prisma`            | Único dono de migrations, como a spec. Worker Python não altera schema.                                                                                                                                                      |
| Python no worker                           | 3.12 (imagem `python:3.12-slim`)                                         | Spec pede 3.11+; 3.12 é a versão do ambiente de desenvolvimento.                                                                                                                                                             |
| Dependências de PLN / extração / LLM / PDF | **Não instaladas na F0**                                                 | F0 só precisa do processo worker no ar (heartbeat + claim loop). spaCy, sentence-transformers, BERTopic, Anthropic, WeasyPrint etc. entram nas fases 4–6.                                                                    |
| `AdminAuditLog`                            | Incluído no schema Prisma da F0                                          | A seção 6 da spec não lista o model, mas a seção 8.4 exige a tabela para exportações Bookxpress.                                                                                                                             |
| Nomes SQL                                  | `@@map` / `@map` para `snake_case`                                       | A fila do worker (seção 12.1) usa SQL em `jobs`, `locked_at`, `run_after`. Sem o mapeamento, Prisma geraria `"Job"."lockedAt"` e o worker não veria as linhas.                                                               |
| `packages/shared`                          | Pacote pnpm sem código JS; só `schemas/*.json`                           | Spec descreve schemas JSON compartilhados. Schemas de LLM completos entram na F5; a F0 deixa o diretório versionado.                                                                                                         |
| Worker no pnpm workspace                   | `services/worker/package.json` só com scripts (`test` → `uv run pytest`) | Permite `pnpm test` no monorepo sem tratar Python como pacote Node.                                                                                                                                                          |
| Imagens MinIO                              | `ghcr.io/coollabsio/minio` (servidor e `mc` no init)                     | A partir de outubro de 2025 o MinIO community é source-only: `minio/minio` e `minio/mc` saíram do Docker Hub/Quay. Continuamos no produto MinIO (S3-compatível); a imagem da community é buildada a partir do fonte oficial. |
| extra_hosts host-gateway                   | Workers e `minio-init` resolvem `postgres`/`minio`/`mailpit` para o host | Em alguns ambientes (Docker aninhado) o bridge overlay/vfs bloqueia tráfego container-a-container; as portas publicadas no host funcionam. Em um daemon normal isso continua válido.                                         |
| `app/global-error.tsx` + `force-dynamic`   | Workaround do Next.js 16.3.6                                             | `next build` (Turbopack) falha ao pré-renderizar `/_global-error` com `useContext` nulo (issues #86178, #95741). Sem mudar de framework.                                                                                     |
| Notebook DataJud                           | Mantido na raiz (`DATAJUD_API_v_final.ipynb`)                            | Já existia neste repositório; fora do escopo do produto, não removido.                                                                                                                                                       |

Nenhum framework, ORM, fila ou serviço fora da seção 3 da spec foi adicionado.
